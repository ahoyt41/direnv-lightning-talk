# Direnv lightning talk

A lightning talk on the direnv environemnt variable manager. This presentation
uses [slides](https://github.com/maaslalani/slides) to render [presentation.md]
as a slide show in the terminal. This tool requires [go][https://go.dev/dl/] to
to be installed on your system.

Once go is installed, the presentation tool can be installed with

```bash
go install github.com/maaslalani/slides@latest
```

Once the tool is installed, the presentation can be rendered by running

```bash
slides presentation.md
```
